# Bank Customer Churn Prediction & Retention Dashboard

This project is an end-to-end churn analytics application that predicts which bank customers are likely to leave and supports data-driven retention decisions through an interactive Streamlit dashboard.

## Project Goal

The goal is to identify high-risk customers, understand the key drivers of churn, estimate potential revenue at risk, and recommend targeted retention strategies.

## Tech Stack

- Python
- Pandas
- NumPy
- Streamlit
- Scikit-learn
- XGBoost
- Plotly
- Lifelines
- GitHub

## Planned Features

- Customer churn overview
- Exploratory data analysis
- Customer segmentation
- K-Means customer personas
- Churn prediction model
- Survival analysis
- Revenue at risk analysis
- Customer risk scoring
- Retention strategy recommendations
- Interactive customer explorer

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
