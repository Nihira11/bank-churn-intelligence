# Customer Churn & Retention Analytics Platform

This project is an end-to-end customer churn analytics web application built using Python, Streamlit, machine learning, and business analytics.

## Project Goal

The goal is to identify customers who are likely to churn and provide data-driven retention recommendations.

## Tech Stack

- Python
- Pandas
- Streamlit
- Scikit-learn
- XGBoost
- Plotly
- PostgreSQL
- GitHub

## Features

- Customer churn overview
- Exploratory data analysis
- Churn prediction model
- Customer risk segmentation
- Revenue at risk analysis
- Retention strategy recommendations

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
